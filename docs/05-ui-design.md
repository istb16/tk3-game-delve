# 05. UI 設計

## 5.1 デザイン方針

**「ミニマルなピクセルアート × モダン UI」**

暗い地下ダンジョンの雰囲気を出しつつ、情報の可読性を最優先する。
雰囲気作りが情報を読みにくくしたら、それは失敗。

- 描き込みすぎない幾何学的な SVG アイコン
- 演出はゲームプレイを妨げない範囲（アニメーションは 200ms 以内）
- 色数を絞り、意味を持たせる（赤 = 危険 / 金 = 報酬 / 青 = 回復 / 紫 = レア）

## 5.2 カラートークン

CSS カスタムプロパティとして `:root` に定義する。

| トークン | 値 | 用途 |
|---|---|---|
| `--bg` | `#0b0d12` | 画面背景（最も暗い） |
| `--surface` | `#141822` | パネル背景 |
| `--surface-2` | `#1d2330` | タイル（床） |
| `--wall` | `#2b3242` | 壁 |
| `--text` | `#e8ecf4` | 主テキスト |
| `--text-dim` | `#8b93a7` | 補助テキスト |
| `--accent` | `#f5a524` | 金・ハイライト |
| `--danger` | `#e5484d` | HP・ダメージ |
| `--heal` | `#30a46c` | 回復 |
| `--info` | `#4a90d9` | 経験値・情報 |
| `--rare` | `#a855f7` | レア装備 |

配色は暗所コントラストを確保し、`--text` / `--bg` 間で 12:1 以上を維持する。

## 5.4 ダンジョン描画

1 枚の `<svg viewBox="0 0 15 15">` として描画し、タイル 1 マスを 1 単位とする。
CSS で `width: 100%; aspect-ratio: 1` にすれば、レスポンシブが自動的に成立する。

```html
<svg viewBox="0 0 15 15" class="board">
  <g class="tile tile--floor" transform="translate(3,4)">
    <rect width="1" height="1" />
  </g>
  <g class="actor actor--player" transform="translate(7,7)">
    <!-- player sprite -->
  </g>
</svg>
```

`transform="translate(x,y)"` に `transition` を掛けることで、移動が滑らかに補間される。

## 5.5 SVG スプライト

すべて `viewBox="0 0 1 1"` 相当の 1 マス内に収まるよう設計し、`src/ui/sprites.ts` に文字列として定義する。

| Rat | 低く平たい菱形 + 尻尾の曲線 |
| Goblin | 角のある三角形の頭 + 短い胴 |
| Skeleton | 頭蓋の円 + 目の黒点 2 つ + 肋骨の横線 |
| Bat | 中央の小円 + 左右の三角の翼 |
| Slime | 底が平らな半円。上辺を波形に |
| Warden | 縦長の六角形 + 内側の発光する菱形 |
| Boss | 二重の六角形 + 中央の目 |
| Wall | 角丸矩形 + 上辺のハイライト線 |
| Floor | 塗りのみ。極薄いグリッド線 |
| Stairs | 3 段の階段を表す階段状のパス |
| Chest | 矩形 + 帯 + 錠前の小円 |

## 5.6 演出

すべて CSS アニメーション。JS はクラスの付け外しのみを行う。

| 演出 | 実装 | 時間 |
|---|---|---|
| 移動 | `transform` の `transition` | 120ms |
| 攻撃 | 対象方向へ 0.2 マス突進して戻る `@keyframes lunge` | 150ms |
| 被弾 | `--danger` へのフラッシュ + 微小な振動 | 200ms |
| 撃破 | `scale(0)` + `opacity: 0` | 180ms |
| 宝箱開封 | 蓋部分の回転 + 光の放射 | 250ms |
| 階段降下 | 画面全体の暗転 → 新フロア表示 | 200ms |
| レベルアップ | プレイヤーを中心に広がる光輪 | 400ms |
| ダメージ数値 | タイル上に浮上してフェード | 600ms |

`prefers-reduced-motion: reduce` に対応し、該当時はすべての `animation` / `transition` を無効化する。

## 5.7 モーダル

`phase` が `levelup` / `event` / `dead` のとき表示する。共通コンポーネント 1 つで賄う。

```
┌──────────────────────────────┐
│        LEVEL UP!             │
│        You are now Lv 6      │
│                              │
│  ┌────────┐┌────────┐┌──────┐│
│  │Sharpened││Vitality││Shield││
│  │+10% ATK ││+15 MHP ││ ...  ││
│  └────────┘└────────┘└──────┘│
└──────────────────────────────┘
```

- 選択肢は `1` `2` `3` キーでも選べる（マウスに手を移さず遊べる）。
- 死亡モーダルは `DELVE AGAIN` にフォーカスを当て、`Enter` / `Space` で即再開。

## 5.8 初見プレイヤーへの説明

チュートリアルは出さない。画面下部に常時 1 行だけ置く。

```
Move: WASD / Arrow Keys        Explore. Fight. Descend.
```

初回起動時（`totalRuns === 0`）のみ、最初の 3 ターンだけ薄いヒントを重ねる。

## 5.9 アクセシビリティ

- キーボードのみで全操作が完結する。
- モーダルはフォーカストラップを持ち、`Esc` で閉じられるものは閉じる。
- 色だけに意味を載せない（HP バーには数値を併記、レア装備には枠線の差も付ける）。
- `prefers-reduced-motion` を尊重する。
