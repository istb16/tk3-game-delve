# 01. 要件定義

## 1.1 コンセプト

**DELVE** — *Go deeper. Survive longer.*

プレイヤーは地下ダンジョンを 1 マスずつ探索し、敵を倒し、アイテムを集め、できるだけ深い階層まで進む。

ルールは単純だが、以下の要素の掛け合わせでリプレイ性を生む。

```
ランダム生成 × キャラクター成長 × 装備 × ビルド × リスク判断
```

死んだら最初から。だからこそ「あと1階だけ」と思わせる。

## 1.2 コアゲームループ

このループの完成度がゲームの品質そのもの。ここを最優先で作る。

```
探索する → 敵を見つける → 戦う → アイテムを得る → 強くなる → より深く潜る → 死ぬ → もう一度挑戦する
```

## 1.3 プレイヤーに発生させたい判断

常に「得か損か」の天秤を置く。以下は設計時のチェックリストとして使う。

- この敵を倒せば経験値が入る。でも HP が残り少ない。
- この宝箱を開ければ強い装備が出るかもしれない。でも罠かもしれない。
- 回復アイテムを今使うか、後まで取っておくか。
- 階段が見えた。フロアを探索し尽くすか、安全なうちに降りるか。
- 祭壇は攻撃力 +20% をくれるが最大 HP が −10 される。受けるか。

## 1.4 機能要件

### FR-1 ダンジョン
- 15 × 15 のグリッド。
- 毎回ランダム生成。
- **スタート地点から階段まで必ず到達可能**であることを保証する（→ [06](06-dungeon-generation.md)）。
- 配置要素: プレイヤー / 敵 / 壁 / 床 / 階段 / 宝箱 / ゴールド / 回復アイテム / 武器 / 特殊マス。

### FR-2 操作
- キーボード: `↑/W` `↓/S` `←/A` `→/D` で 1 マス移動。
- マウス / タップ操作にも対応（方向パッド）。
- 1 キー = 1 マス移動 = 1 ターン。リアルタイム要素は持たない。
- 押しっぱなしによる連続移動を許可する。ただし**被弾・新たな敵の出現・階層移動で
  必ず中断する**（→ [05 §5.11](05-ui-design.md)）。気づかないうちに死ぬ状態を作らない。

### FR-3 ターン制
- プレイヤーが 1 行動すると、全ての敵が 1 ターン行動する。
- 敵ごとに移動速度を持ち、速度に応じて行動回数が変わる。

### FR-4 戦闘
- プレイヤーと敵が隣接した状態で敵方向へ移動入力すると攻撃。
- ダメージ = `攻撃力 − 防御力`（下限 1）。
- 敵はプレイヤーへ接近する簡易 AI を持つ。
- 敵種: Rat / Goblin / Skeleton / Bat / Slime / Warden / Boss。
- 敵は HP・攻撃力・防御力・移動速度・特殊能力・経験値を持つ。

### FR-5 成長
- 敵撃破で経験値を獲得し、閾値でレベルアップ。
- レベルアップで最大 HP・攻撃力・防御力が上昇。
- レベルアップ時にパークを **3 択から 1 つ選択**（ビルドの分岐点）。

### FR-6 装備
- スロット: Weapon / Armor / Ring。
- 武器は Attack / Critical / 特殊効果を持つ。
- 装備はダンジョン内でランダムに入手。

### FR-7 アイテム
- Potion（HP 回復）/ Bomb（周囲の敵・壁に影響）/ Scroll（ランダム効果）/ Key（施錠された宝箱を開ける）。

### FR-8 階層システム
- 階段で次の階へ。**階を進むごとに難易度が上がる。**
- 難易度は「敵のHPを増やす」ではなく、次の5つのレバーで作る（→ [07](07-difficulty.md)）。
  1. ステータススケーリング（防御力の伸びは最小に）
  2. 敵の数
  3. 敵構成の連続的な入れ替え（弱い敵の比率が滑らかに下がる）
  4. 回復資源の相対的な減少
  5. フロア構造の複雑化
- 基準: **上手くないプレイヤーが 10〜15 階で終わる**（1プレイ 10〜20 分）。
- 一定階層ごと（5 の倍数階）にボスが登場。
- レアアイテムと特殊イベントの出現率も深度とともに上がる。

### FR-9 ランダムイベント
- 一定確率で発生。Mysterious Shrine / 商人 / 呪われた宝箱 / 回復の泉 / 謎の祭壇 / 隠し部屋 / 宝物庫。
- 選択肢を提示し、リスクとリターンを釣り合わせる。

### FR-10 死亡とリプレイ
- HP が 0 で死亡。`YOU DIED` を表示。
- リザルト: 到達階層 / 撃破数 / 獲得ゴールド / プレイ時間 / レベル。
- `DELVE AGAIN` で即座に新規開始。**ロード待ちを発生させない。**

### FR-11 記録の永続化
- localStorage に保存: 最高到達階層 / ハイスコア / 実績 / 累計撃破数。
- 実績: First Blood / Deep Diver / Treasure Hunter / Slayer / Boss Killer / 100 Kills / Floor 10 / Floor 25 / Floor 50。

### FR-12 キャラクター表現
- キャラクターと地形は**後期ファミコン期のドラゴンクエスト風ドット絵**にする。
- 1 スプライト = **16 × 16 ピクセル**、正面向きのみ。
- **2 枚のフレームを切り替えて歩いているように見せる。**
  切り替えは移動に成功したタイミングで行い、静止中はアニメーションしない。
- HUD・ログ・モーダルはドット絵にせず、現代的な UI として可読性を優先する。
- 詳細は [05](05-ui-design.md)。

### FR-13 favicon
- ブラウザタブ用の favicon を持つ。
- 単一 HTML ファイルなので **data URI として埋め込む**。外部ファイルは置けない。
- プレイヤーのスプライトから生成し、ドット絵の定義を二重に持たない。

### FR-14 サウンド
- Web Audio API で効果音を生成（攻撃 / 被弾 / レベルアップ / 取得 / 階段 / 死亡）。
- 外部音声ファイルは使わない。**デフォルト OFF**、トグルで有効化。

## 1.5 非機能要件

| ID | 要件 |
|---|---|
| NFR-1 | 出荷物は **単一 HTML ファイル**。ブラウザで開くだけで動作する |
| NFR-2 | ランタイムの外部ライブラリ **ゼロ** |
| NFR-3 | 外部画像ファイルを使わない。画像はすべて**インライン SVG** |
| NFR-4 | サーバー / バックエンド不要。ネットワークアクセスなしで完動する |
| NFR-5 | レスポンシブ。デスクトップ / タブレット / スマートフォンで遊べる |
| NFR-6 | 初見のプレイヤーが **30 秒以内**にルールを理解できる。長いチュートリアルを出さない |
| NFR-7 | 入力から描画反映まで 16ms 以内（1 フレーム）を目標とする |
| NFR-8 | リスタートは即時。ローディング画面を挟まない |
| NFR-9 | ドット絵の描画に外部画像を使わない。SVG の `<symbol>` + `<use>` で表現する |
| NFR-10 | 演出はターン処理をブロックしない。入力に対する応答を演出の完了より優先する |

## 1.6 スコープ外

- マルチプレイ / オンラインランキング
- アカウント登録・サーバー保存
- 外部アセット（画像・音声・フォントファイル）の読み込み
